# 🔭 Solarmax Home Observatory – AstroSampling

Calcolatore di campionamento astronomico ottimizzato per telescopi Tecnosky e camere ZWO / Player One.

---

## 📱 Come installarlo su Xiaomi (Android) come app

### Passo 1 – Pubblica su Vercel (gratis, 5 minuti)

1. Vai su **https://github.com** e crea un account gratuito (se non ce l'hai)
2. Clicca **"New repository"** → chiama il progetto `astrosampling` → clicca **"Create repository"**
3. Clicca **"uploading an existing file"**
4. Carica **tutti i file e le cartelle** di questo ZIP mantenendo la struttura
5. Clicca **"Commit changes"**

### Passo 2 – Collega Vercel

1. Vai su **https://vercel.com** e accedi con il tuo account GitHub
2. Clicca **"Add New Project"**
3. Seleziona il repository `astrosampling`
4. Lascia tutto com'è e clicca **"Deploy"**
5. Dopo 1-2 minuti ricevi un URL tipo `astrosampling.vercel.app` 🎉

### Passo 3 – Installa sul Xiaomi

1. Apri **Chrome** sul tuo Xiaomi
2. Vai all'URL che ti ha dato Vercel
3. Tocca i **tre puntini** in alto a destra
4. Seleziona **"Aggiungi a schermata Home"** o **"Installa app"**
5. Conferma → l'icona del telescopio appare nella home!

L'app funziona **anche senza connessione internet** grazie alla cache PWA.
